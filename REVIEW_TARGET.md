# Review target

This repository is intentionally engineered for the highest GenLayer rubric ceiling, but no score is assumed before live evidence is produced.

## GenLayer Fit target

The semantic result controls a public replication record and optional reward reservation. Neither the original author nor the replicator is trusted to self-certify protocol compliance or evidentiary sufficiency. The validators retrieve evidence and independently reconstruct the finding.

## Contract Quality target

- Three coherent contract boundaries.
- Independent leader/validator evidence retrieval.
- Evidence snapshot receipts bind URL/origin/fetch status/bounded content digest and are validator-matched.
- Material-field comparison, not format-only validation.
- Explicit `INCONCLUSIVE` and `PROTOCOL_DEVIATION` outcomes.
- No default winner or positive result.
- Frozen reward policy.
- Parent-finalized-only cross-contract outcome message, plus explicit child-finality verification in the live evidence bundle.
- Replay prevention in the final record registry.
- Pull-based reward withdrawal.
- Bounded evidence inputs, optional frozen source-origin policy, stable evidence-window commitments and hostile-evidence prompt rule.

## Engineering target

Before submission the finishing agent must produce green GenVM lint, Direct Mode tests, frontend typecheck/build, live 61999 deployment manifests, finalized deployment transactions, real write/read browser proof, and documented edge-case tests.

## Frontend target

The product must be genuinely usable without exposing ABI-shaped forms. It must distinguish provisional consensus from archive records, support wrong-network and wallet errors, be responsive, and use the five clean-room routes only.
