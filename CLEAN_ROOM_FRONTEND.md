# Clean-room frontend rule

REPROVE is a clean-room frontend implementation.

Do **not** copy, adapt, import, restyle, translate, refactor or use as a structural reference any frontend code, JSX, CSS, navigation model, component hierarchy, page route hierarchy, page composition, interaction pattern, branding treatment or UI copy from any repository under `github.com/ometere123`.

Do **not** use PATHCLOCK as a frontend reference. Do not copy its `/console`, `/release/[reviewKey]`, `/proof/[receiptKey]`, release-room interaction model, security-review layout, evidence drawer, transaction presentation or warm paper/rust/amber/green palette.

REPROVE's required product language is:

- Replication Atlas
- registered study / claim
- frozen protocol paper
- replication notebook
- evidence leaves
- replication matrix
- independent evaluation
- archive record

Required routes are exactly:

`/`, `/lab`, `/claim/[studyKey]`, `/attempt/[attemptKey]`, `/archive/[recordKey]`.

The visual palette is cool and research-oriented: glacier blue, deep navy, cobalt, violet, magenta and cyan. The release guard rejects PATHCLOCK's warm palette tokens and banned route/component names.
